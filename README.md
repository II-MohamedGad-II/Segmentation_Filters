# Segmentation Filters

This repository contains a Jupyter Notebook implementing various image segmentation filters using OpenCV and NumPy. The notebook demonstrates techniques such as edge detection and image enhancement through custom filtering.

## Features
- Image processing with OpenCV
- Application of various segmentation filters
- Implementation of the Prewitt edge detection filter
- Visualization of results using Matplotlib

## Repository Structure
- `SegmentationFilters.ipynb` - Contains code for loading images, applying segmentation filters, and displaying results.

## Requirements
To run this project, install the following dependencies:

```bash
pip install opencv-python numpy matplotlib
```

## Usage
1. Open `SegmentationFilters.ipynb` in Jupyter Notebook.
2. Run the cells sequentially to load an image and apply various segmentation filters.
